# Executor: Ollama

Ollama — механизм локального выполнения модели. Подходящие Role: `Classifier` для заданных категорий и `Writer` для коротких резюме/черновиков. Это не отдельная роль «локальный клерк». Общая запись механизма — в [EXECUTORS.md](EXECUTORS.md).

Локальные CLI и endpoint хранятся в `config/local.yaml` под `executors.Ollama`; они не являются публичной конфигурацией. Модель записывается отдельно в карточке, в `model` или `review.model`.

## Ручное использование

Перед назначением проверь доступность службы и нужной модели. Системный запуск требует соответствующего поручения; изменение статуса карточки сервер не запускает. После подтверждённого запуска можно открыть ручной диалог:

```bash
ollama list
ollama run llama3.2:3b
```

Пример поручения для Role `Classifier`: «Разнеси переданные записи по категориям code, docs, research. Для каждой дай ID, категорию и неопределённость. Ничего не выполняй».

## Ограничения

В текущей настройке модель получает только переданный текст. Доступ к файлам проекта, shell, Git, поиск, вызов инструментов и автоматическая передача задач не подключены. Ответ сверяется с источниками. Служба и модели остаются вне репозитория; их перенос или автоматический запуск не входит в нормализацию документов.

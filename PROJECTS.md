# Проекты

Project key — устойчивый идентификатор проекта. Физический корень хранится только в `config/local.yaml`, в `projects.<project_key>`. Отсутствующий или пустой корень требует уточнения; путь не угадывается.

| Project key | Проект | Назначение и границы |
| --- | --- | --- |
| `skeletoncrew` | SkeletonCrew | Ручная диспетчерская, документы, карточки и результаты. Здесь готовится модель будущего crew-dispatcher v0.1 |
| `rrm` | RRM | Unity/C# прототип тяжёлого физического боя, VHS-камеры и повреждений. Первый игровой проект для портфолио-задачи. Не пересоздавать двухкомнатную сцену и не запускать builder без прямого поручения |
| `hanabi_western` | Hanabi Western | Godot/C# игра; доменные правила отделены от интерфейса. Локальный корень — папка решения с её правилами, frontend находится в `hanabi.western`. Диагностика и исправления требуют явно разных границ |
| `legacy_crew_os` | Ранний Skeleton Crew OS | Отдельный прототип, справочный материал. Не подключён к текущему процессу; его команды и правила не наследуются автоматически |

Реестр не хранит статусы задач, состояние Git или результаты игровых проверок. Такие сведения фиксируются с датой и источником в соответствующей карточке.

Логическая ссылка `rrm:AGENTS.md` означает файл относительно корня `rrm`; `skeletoncrew:outputs/rrm-round-lifecycle-case.md` — результат в рабочем центре. Конкретные пути не вставляются обратно в публичные документы.

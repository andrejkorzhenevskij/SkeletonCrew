# RRM AI-assisted PR Case

## Goal

Подготовить черновик портфолио-кейса об одной фиче проекта `rrm`: завершение раунда и фиксированный итоговый отчёт камеры. Название задачи не означает существование PR для этой фичи.

## Context

- Реестр: [PROJECTS.md](../PROJECTS.md); правила рабочего центра: [AGENTS.md](../AGENTS.md). Инструкции игрового проекта: `rrm:AGENTS.md`.
- Начальные источники: `rrm:Assets/RRM/README.md`, `rrm:Assets/RRM/Scripts/RoundManager.cs`, `rrm:Assets/RRM/Scripts/RoundSnapshot.cs`, `rrm:Assets/RRM/Scripts/CameraRecorder.cs`, `rrm:Assets/RRM/Scripts/Damageable.cs`, `rrm:Assets/RRM/Editor/CombatPrototypeRoundCheck.cs`.
- При первоначальной подготовке карточки 2026-09-21 README описывал цикл `Waiting → Active → Ending → Finished`; названные файлы существовали, рабочее дерево содержало незакоммиченные изменения. Файлы раундов ещё не были добавлены в Git. Это исторический снимок, который нужно перепроверить перед кейсом; при нормализации карточки игровой проект не исследовался заново.
- Нельзя приписывать текущую фичу старому коммиту или выдуманному PR. Логи и изображения используются с датой и происхождением. Утверждение README, просмотренный лог и новый запуск — разные уровни свидетельств.

## Constraints

- Разрешены чтение проекта `rrm`, запись результата по полю `output` и обновление этой карточки в `skeletoncrew` после начала задачи.
- Не изменять игровой проект и его Git, не запускать Unity, тесты, builder, сборку или экспорт.
- Не копировать весь проект, логи или сторонние ассеты в публичный рабочий центр.
- Не заявлять production readiness, релиз или независимое ревью без свидетельств.
- Вклад AI и человека подтверждать записями; неизвестное оставить вопросами капитану.
- Готовится локальный черновик. Публикация и платные API в задачу не входят. Абсолютные пути компьютера в результат не включать.

## Expected Output

Один Markdown-файл по логической ссылке `output`: короткий русский кейс с проблемой, поведением до/после, решением, проверками, вкладом AI/человека, ограничениями и источниками. Вопросы без ответа вынести отдельно.

## Done Criteria

- [ ] Описана одна фича, RRM явно назван прототипом.
- [ ] Существенные утверждения имеют логические ссылки на файлы/строки или проверенные исторические материалы с датами.
- [ ] Незакоммиченная работа отделена от истории Git; PR упомянут только при подтверждённом существовании.
- [ ] Проверки разделены на текущие, исторические и невыполненные.
- [ ] Вклад AI/человека подтверждён или помечен как неизвестный; неизвестное допустимо для черновика, не для публичного утверждения.
- [ ] Проверка Role `Reviewer` завершена; её Executor, автор/сеанс, способ и ограничения записаны в `Verification`.
